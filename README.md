# Инструмент для объединения файлов

Небольшая утилита на Python для объединения нескольких текстовых файлов в один с сортировкой по количеству строк.  
Разработано с учётом QA‑подхода: полное покрытие тестами, статический анализ (Pylint) и CI/CD‑пайплайн.

## 🧪 Возможности

- Объединение нескольких `.txt` файлов в один выходной файл.
- Сортировка содержимого по количеству строк в файле (по возрастанию).
- Корректная обработка отсутствующих файлов (пропускаются без ошибок).
- Полное покрытие тестами через `pytest` и отчёты о покрытии.
- Статический анализ кода с помощью `pylint` (оценка 10.0/10).
- Пайплайн CI на GitHub Actions (тесты + линтинг + покрытие).

## 🚀 Быстрый старт

### Предварительные требования
- Python 3.13+
- Виртуальное окружение (`venv`)

### Установка

```bash
# Создание и активация виртуального окружения
python -m venv .venv
# Для Windows:
.venv\Scripts\activate
# Для macOS/Linux:
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
pip install pylint pytest pytest-cov
Запуск скрипта
bash
python run_merge.py
По умолчанию объединяются файлы data/1.txt, data/2.txt в output/all_files.txt.
```
## 🧪 Запуск тестов и проверка покрытия
```bash
pytest -v
pytest --cov=file_merger --cov-report=term-missing 
```
Отчёт о покрытии будет сгенерирован в htmlcov/index.html.

## 🔍 Статический анализ
```bash
pylint --rcfile=.pylintrc file_merger.py run_merge.py tests/test_file_merger.py
```
## 🛠️ CI/CD‑пайплайн
В проекте настроен пайплайн на GitHub Actions (python-app.yml), который:

- Устанавливает зависимости.
- Запускает pylint с кастомной конфигурацией для корректной обработки импортов.
- Выполняет pytest с отчётом о покрытии кода.
- Останавливает сборку, если есть предупреждения линтера или упавшие тесты.

Статус пайплайна: ![CI Status](https://github.com/nanaluix-ship-it/oook/actions/workflows/python-app.yml/badge.svg)

💡 Обязательно замени ТВОЙ_НИК_НА_GITHUB на свой никнейм на GitHub, чтобы бейдж реально отображал статус пайплайна.

📝 QA‑заметки
